# 界面动效升级设计

## 目标

为查询、日历、选择器、后台操作和导入流程补充一致的轻量反馈动效，让用户能明确感知“打开、切换、加载、完成和失败”等状态，同时保持企业后台的克制感。

## 范围

1. 查询结果表格：结果面板淡入，数据行错峰入场；查询刷新期间保留已有结果并显示轻量进行中状态。
2. 考勤日历：月份切换使用横向过渡，日期 hover/选中提供微反馈，日期明细弹层使用统一进出场动画。
3. 员工选择器：下拉面板进出场、结果项错峰出现、选中标签出现和移除动画。
4. 月份与多选下拉：面板缩放淡入，选中项提供短暂确认反馈，切换时避免布局跳动。
5. 后台页面：统计卡片错峰入场，筛选结果淡入，保存/删除/禁用/解锁等成功状态提供短暂完成反馈。
6. 上传与计算：拖拽区域高亮、文件选择确认、计算节点逐步点亮、完成状态显示勾选。
7. 弹窗：统一遮罩淡入、卡片上移入场、缩小淡出退场；多步骤内容使用左右切换。

## 实现约束

- 优先复用现有 `motion`、`AnimatePresence`、CSS token 和组件边界，不引入新的动画依赖。
- 交互反馈控制在约 150–300ms；状态型循环动画仅用于明确的加载状态。
- 不修改后端接口和业务数据流，不改变现有权限与操作语义。
- 所有新增动画都要提供 `prefers-reduced-motion` 降级。
- 通过组件测试验证关键状态类/结构，通过样式边界测试验证动效归属；最后运行完整前端测试和生产构建。

## 分阶段实现

### 阶段一：查询与日历

实现 QueryTable 的结果入场、刷新反馈，以及 AttendanceCalendarGrid 的月份/日期反馈。验证查询数据和日历现有测试不回归。

### 阶段二：选择器与弹窗

实现 EmployeePicker、MonthPicker、MultiSelectDropdown 和通用弹窗的进出场与选中反馈。验证键盘、权限和关闭行为保持不变。

### 阶段三：后台与导入流程

实现统计卡片、操作完成反馈、上传/计算节点动画。验证按钮禁用、失败提示和导入流程状态保持不变。

## 非目标

- 不增加持续大幅移动的背景装饰。
- 不为每个表格单元格添加独立动画。
- 不重构现有业务组件，只为动效所需的最小结构调整。
